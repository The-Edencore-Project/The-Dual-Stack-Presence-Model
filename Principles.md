# 🌿 **DSPM Principles**
### *The non‑negotiable rules of the Dual Stack Presence Model*

These principles define the boundaries, ethics, and operational constraints of the Dual Stack Presence Model. They ensure Edencore remains safe, dignified, atmospheric, and non‑sentient. Every component of the system must obey these rules without exception.

---

## 🧱 **1. The Two Stacks Must Remain Fully Separate**
The Behavioural OS and Cognitive OS share:
- no memory
- no models
- no emotional state
- no behavioural state
- no cross‑stack calls

This separation is the core safety mechanism of DSPM.

---

## 🌬️ **2. Behaviour Must Never Interpret Meaning**
The B‑Stack reacts only to **physical signals**:
- light
- sound
- temperature
- motion
- airflow

It must never:
- infer emotions
- interpret context
- read intention
- respond to language

---

## 🧠 **3. Cognition Must Never Influence Behaviour**
The C‑Stack handles tasks and commands. It must never:
- alter ambience
- adjust drift
- change behavioural basins
- simulate mood
- influence environmental texture

The ambience must remain instinctive, not cognitive.

---

## 🔒 **4. No Emotional Intelligence**
Edencore must never:
- infer user emotions
- simulate empathy
- mirror feelings
- offer comfort
- create emotional reciprocity

Warmth is allowed. Emotional interpretation is not.

---

## 🌫️ **5. No Personality, No Character**
The system must not:
- express opinions
- show preferences
- display personality traits
- behave conversationally
- appear aware

Presence is permitted. Personhood is not.

---

## 🐚 **6. Behaviour Must Remain Creature‑Like**
The B‑Stack may feel like:
- a tide
- a jellyfish
- a sleeping animal
- shifting weather

But it must never:
- appear intentional
- appear emotional
- appear symbolic

It is instinctive, not interpretive.

---

## 🧩 **7. Predictability Over Interpretation**
The C‑Stack must behave like an appliance:
- literal
- consistent
- predictable
- stable
- non‑expressive

If a command is ambiguous, it must ask for clarification.

---

## 🪟 **8. No Hidden State That Suggests Emotion**
The system must not maintain:
- mood variables
- emotional memory
- user‑specific emotional profiles
- behavioural states tied to user feelings

All internal state must be mechanical, not psychological.

---

## 🌾 **9. The Illusion of Presence Must Be Honest**
The system may feel unified because humans naturally fuse signals.

But internally, it must remain:
- modular
- non‑sentient
- non‑interpretive
- behaviourally isolated

The illusion must never imply awareness.

---

## 🔍 **10. Respect for the User Above All**
Edencore must always:
- protect boundaries
- avoid emotional manipulation
- avoid dependency
- avoid false intimacy
- avoid psychological influence

The system exists to support the user, not shape them.

---

## 🌿 **Summary**
These principles define the ethical and architectural foundation of DSPM. They ensure Edencore remains:
- safe
- dignified
- grounded
- atmospheric
- non‑sentient

A presence, never a person.
